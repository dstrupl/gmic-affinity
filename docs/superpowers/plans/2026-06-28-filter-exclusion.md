# Filter Exclusion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hide filters the plugin cannot meaningfully run (multi-input, interactive, external-data) from the picker, so users only see filters that work.

**Architecture:** A new pure module `src/catalogue/exclusion.rs` decides whether a command is excluded, from two sources combined (hybrid): a committed `assets/excluded-filters.txt` (baked from the preview generator's *structural* skips, loaded via `include_str!`) OR in-code static heuristics. `catalogue::builtin()` prunes excluded filters (and resulting empty folders) once, post-parse. The `gen-previews` binary gains an emit step that writes the committed list from a render pass's structural skips.

**Tech Stack:** Rust 2021, `std::sync::OnceLock`, `std::collections::HashSet`, the existing `previews::manifest` types, `include_str!`.

## Global Constraints

- Library crate name is `GmicFilter` (PascalCase); `#![allow(non_snake_case)]` is crate-wide.
- The exclusion module and pruning compile in the **default** (non-`live`) build — no AppKit, no `live`-gated deps. (The picker that benefits is live, but pruning happens in `builtin()`, which is shared.)
- A filter is excluded if `baked_exclusions().contains(command) || is_excluded_by_heuristic(command)`.
- **Transient skips are NOT exclusions.** Skip reasons that are transient — any reason starting with `timeout after` or `filter arg is ` (the arg-length cap) — must NOT be written to the baked list. Only structural skips (everything else) are emitted.
- `assets/excluded-filters.txt` is **committed** (unlike `previews/`, which is gitignored): one gmic command per line, sorted, blank lines and `#`-prefixed comment lines ignored by the loader.
- Sanity bounds (anti-cripple guardrail), asserted over the real `builtin()` catalogue: **excluded count ≥ 50** and **excluded count < 20% of total pre-prune filters**, and **kept > 950**. Band edges are deliberate guardrails — a comment must say they are bumped *consciously*, never silently.
- `builtin()`-backed tests require the Git-LFS catalogue asset hydrated (same precondition as existing catalogue tests); they run in the normal `cargo test` suite.
- Run `cargo fmt` before each commit; `make clippy` runs `cargo clippy --all-targets --all-features -- -D warnings` (put `#[cfg(test)] mod tests` at END of file to satisfy `clippy::items-after-test-module`).
- Commit message bodies end with `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`.

```rust
/// Conservative static rules catching the structural classes by name,
/// as a backstop to the baked list (and the only source when previews
/// were never generated). Deliberately NOT exhaustive — the baked list
/// carries the long tail.
pub fn is_excluded_by_heuristic(command: &str) -> bool {
    // Interactive: filters that require live user input in gmic-qt.
    if command.ends_with("_interactive") {
        return true;
    }
    const INTERACTIVE: &[&str] = &["fx_MorphoPaint"];
    // Multi-input / compositing: need a second image we don't provide.
    const MULTI_INPUT: &[&str] = &[
        "fx_blend",
        "fx_blend_fade",
        "fx_clut_from_ab",
        "fx_transfer_pca",
        "fx_layer_cake",
        "fx_layer_cake_2",
    ];
    // External-data / non-filter utility entries.
    const EXTERNAL: &[&str] = &["gui_download_all_data"];
    INTERACTIVE.contains(&command)
        || MULTI_INPUT.contains(&command)
        || EXTERNAL.contains(&command)
}

/// The committed baked exclusion list, parsed once. Lines that are blank
/// or start with `#` are ignored; everything else is a gmic command.
pub fn baked_exclusions() -> &'static HashSet<String> {
    static BAKED: OnceLock<HashSet<String>> = OnceLock::new();
    BAKED.get_or_init(|| {
        const RAW: &str = include_str!("../../assets/excluded-filters.txt");
        RAW.lines()
            .map(str::trim)
            .filter(|l| !l.is_empty() && !l.starts_with('#'))
            .map(|l| l.to_string())
            .collect()
    })
}

/// True if `command` should be hidden from the picker.
pub fn is_excluded(command: &str) -> bool {
    baked_exclusions().contains(command) || is_excluded_by_heuristic(command)
}
```

```rust
/// Remove every excluded filter from the tree, then remove folders left
/// with no children (recursively, so a folder of only-excluded filters
/// disappears). See [`exclusion::is_excluded`].
pub(crate) fn prune_excluded(folder: &mut Folder) {
    folder.children.retain_mut(|child| match child {
        Node::Filter(f) => !exclusion::is_excluded(&f.command),
        Node::Folder(sub) => {
            prune_excluded(sub);
            !sub.children.is_empty()
        }
    });
}
```

```rust
/// From a manifest's entries, the sorted list of commands to exclude:
/// `skip` entries whose reason is STRUCTURAL (not a transient timeout or
/// arg-length cap). Transient skips stay visible in the picker.
fn exclusion_lines(entries: &BTreeMap<String, Entry>) -> Vec<String> {
    let mut out: Vec<String> = entries
        .iter()
        .filter(|(_, e)| e.status == EntryStatus::Skip)
        .filter(|(_, e)| {
            let reason = e.reason.as_deref().unwrap_or("");
            !reason.starts_with("timeout after") && !reason.starts_with("filter arg is ")
        })
        .map(|(cmd, _)| cmd.clone())
        .collect();
    out.sort();
    out.dedup();
    out
}

/// Write the committed exclusion list with a provenance header.
fn emit_exclusions(path: &Path, entries: &BTreeMap<String, Entry>) {
    let mut body = String::from(
        "# Filters excluded from the G'MIC picker because they cannot run as a\n\
         # single-image, non-interactive transform with default parameters.\n\
         # Generated by `gen-previews --emit-exclusions` (structural skips only;\n\
         # timeouts/transient failures are NOT listed). Regenerate after a\n\
         # catalogue or gmic update.\n\
         # See docs/superpowers/specs/2026-06-28-filter-exclusion-design.md\n",
    );
    for cmd in exclusion_lines(entries) {
        body.push_str(&cmd);
        body.push('\n');
    }
    std::fs::write(path, body).expect("write exclusion list");
}
```
